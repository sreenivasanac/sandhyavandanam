# Content guide — `app/src/content/sandhya.json`

The whole ritual is one JSON file validated by `app/src/content/schema.ts` (zod). Contributors edit **IAST only**; other scripts are generated by `pnpm xlit` (aksharamukha).

## Shape
```jsonc
{ "version": "x.y.z", "steps": [ Step, … ] }
Step  = { id, title:{sa,en}, section:"purvanga"|"uttaranga", intro?, facing?:{pratah,madhyahnika,sayam}, image?,
          items:[Item…], sources?:[…], kala?:[…], tradition?:[…], optional? }
Item  = { kind:"mantra", text:{iast, devanagari?, tamil?, …}, meaning?, action?, repeat?, audio?, verified?, kala?, tradition?, optional? }
      | { kind:"note", text, kala?, tradition?, optional? }
```
- `kala` / `tradition` omitted = applies to all. Put kāla-specific mantras as **separate items** tagged `kala:["pratah"]` etc. Same for `tradition:["smarta"]` / `["srivaishnava"]`.
- `repeat`: number or `{pratah:3, madhyahnika:2, sayam:3}`.
- `optional:true` = "some families do this" (rendered with a marker; can be hidden later).
- `sources`: cite PDF + page (`"Kidambi p45"`, `"sandhya.pdf p13"`) so reviewers can check.
- `verified:true` only after a knowledgeable human has checked the item.

## IAST conventions (canonical text)
- Standard IAST: ā ī ū ṛ ṝ ḷ ṃ ḥ ṅ ñ ṭ ḍ ṇ ś ṣ. Anusvāra `ṃ`; visarga `ḥ`; avagraha `'`.
- Vedic svaras as combining marks on the vowel: anudātta `̱` (U+0331), svarita `̍` (U+030D), dīrgha-svarita `̎` (U+030E). Example: `dhiyo̱ yo na̍ḥ praco̱dayā̎t`.
- Yajur "gṃ" nasal: write `guṃ` (e.g. `oguṃ suvaḥ`, `āyūguṃṣi`) — matches Tamil/Kannada printed usage.
- Line breaks inside a mantra with `\n`; pādas separated by ` | `, verse end ` || `.
- Placeholders substituted at runtime, all IAST: `{name} {gotra} {pravara} {arsheya} {sutra} {kala} {kalaEn} {panchanga}`.

## Prose (`intro`, `action`, `meaning`, `note`)
- English, plain, imperative for actions ("sip water", "sprinkle on the head").
- `*…*` renders italic (used for inline mantra names). No other markdown.
- Meanings: faithful, short; prefer the source's translation (sandhya.pdf, Chakravarthy) and cite.

## Workflow
1. Edit IAST/meanings/actions → `pnpm xlit` (regenerates scripts in place) → `pnpm build` (schema check) → `pnpm test`.
2. Never hand-edit the generated `devanagari/tamil/kannada/telugu/malayalam` fields.
